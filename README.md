## 200M峰值带宽和5M固定带宽，不是一个东西

轻量的“200M带宽”是共享的峰值带宽，u1的“5M带宽”是独享固定带宽，前者数字大，后者更稳定，适用场景完全不同。

峰值带宽指最高能冲到200M，日常速度取决于线路当时的空闲程度，轻量服务器走流量计费模式。5M固定带宽则是独享的，任何时段都保证5M，流量不限、不另计费。

实际影响是：轻量200M那台适合流量不大、访问分散的站点，平时用不满带宽，峰值反而给了突发余量；业务要持续占带宽——稳定的下载、视频流或大量API调用——5M固定带宽的可预期性更重要，不用担心流量账单失控。9.9元的轻量在带宽规格上比很多同价VPS厚道，但“跑得猛”的场景还是固定带宽踏实。
